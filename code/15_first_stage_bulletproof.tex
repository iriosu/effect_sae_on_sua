\maketitle

Estimation-grade version of the \texttt{14\_scarce\_seats.Rmd} finding,
built to survive the obvious attacks. (1) REGRESSION TO THE MEAN: school
sets are defined on a SPLIT-HALF design -- ranked on odd-MRUN 2015
entrants, baselined on even-MRUN 2015 entrants (the SIMCE-8 file carries
tests 2014/2017/2019 only, so cohorts 2015/2018/2020 are the data) --
selection noise independent of baseline noise. (2) INFERENCE the data
can support: the SIMCE-8 test-year gaps make CS base periods infeasible
(wave-2017's base cohort has no test), so the estimator is school-level
LONG DIFFERENCES between dense cohorts -- D18 = cohort 2018 minus the
even-half 2015 baseline, treated-by-2018 (Magallanes + wave-2017) vs
clean controls (wave-2018 at e-1, RM at e-2, both admitted pre-SAE); D20
= cohort 2020 minus pre, all treated, years-of-exposure dose gradient --
with region-cluster-bootstrap SEs AND exact randomization inference over
the 1,001 admissible reassignments of the wave-2017 regions (the \#16
space; Magallanes and RM held fixed). Entry composition is determined at
admission, so there is no transition band and no exam-era, grading or
PAES confound. (3) COVERAGE: dense cohorts set by empirical match rates;
the coverage change is estimated as an outcome (differential-matching
check). Sets: SCREENERS (top-quartile 2012-13 intake, \textgreater=20
matched entrants), HIGH-VA (top-quartile va\_2016), and a PLACEBO set
(bottom-half 2012-13 intake -- no screening to ban, nothing should
move). Closing block: the arithmetic bridge from the first-stage
magnitude to the ceiling on aggregate college effects, against the
within-public +-2pp bounds. Guard chained to
\texttt{11\_adjudication\_trajectories.Rmd}.

\hypertarget{estimation-long-differences-on-dense-cohorts-exact-randomization-inference}{%
\subsection{Estimation: long differences on dense cohorts + exact
randomization
inference}\label{estimation-long-differences-on-dense-cohorts-exact-randomization-inference}}

The SIMCE-8 test-year gaps make CS base periods infeasible (wave-2017's
base cohort has no test), so the estimator is the design the data
supports: school-level long differences between dense cohorts, with the
rollout randomization providing exact inference. Pre = pooled cohorts
2014-15 (dense, post-split). (i) D18 = cohort-2018 minus pre,
TREATED-BY-2018 (Magallanes + wave-2017 regions) vs clean controls
(wave-2018 at e-1, RM at e-2 -- both classes admitted pre-SAE). (ii) D20
= cohort-2020 minus pre: all groups treated, so years-of-exposure
(1/2/3+) gives the dose gradient. Inference: region-clustered SEs and
exact RI over the 1,001 admissible reassignments of the four wave-2017
regions among the fourteen 2017/2018 adopters (the \#16 space;
Magallanes and RM held fixed).
