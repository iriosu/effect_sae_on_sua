\maketitle

Minimum gate agreed in issue \#14 after the adversarial review. Every
gender comparison is reported as Female, Male, and the within-class gap
(female mean minus male mean per school x cohort), with the gap
estimated through the same Callaway--Sant'Anna machinery, so the F\(-\)M
column carries joint region-clustered inference. (1) Pipeline and
take-up gaps with event studies. (2) Application validity as
unconditional counts over all class members (valid applications, invalid
applications, any-invalid indicator), replacing the
applicant-conditional shares. (3) Entrant-ITT rerun of the pipeline: all
9th-grade entrants, outcomes zero-filled, no graduation filters. (4) The
pre-specified direct sorting test: probability that an entrant's
9th-grade school is in the academic (HC) track, on a
commune-of-residence x cohort panel; every region is eventually treated,
so this design has no never-treated arm and leans on timing variation
only. Observations rows count classes with a usable outcome, column by
column. Estimator, seed and sample rules as in
\texttt{3\_effect\_sae\_am.Rmd}; \texttt{did} 2.5.1.

\hypertarget{direct-sorting-test-pacademic-track-commune-panel}{%
\subsection{4. Direct sorting test: P(academic track), commune
panel}\label{direct-sorting-test-pacademic-track-commune-panel}}

Share of a commune's 9th-grade entrants whose school is in the academic
(HC) track, from each entrant's own 9th-grade record; commune of
residence at 9th grade, region from the commune code. Every region joins
SAE, so there is no never-treated arm: identification uses
not-yet-treated timing variation only, and effects for the last-treated
regions are not identified.
