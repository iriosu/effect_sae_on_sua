\begin{document}
\maketitle

Issue \#16: randomization inference over the 1,001 admissible rollout
reassignments, region-level wild cluster bootstrap, COVID / exam-reform
window cuts, wave-by-wave event studies, leave-one-region-out,
student-weighted aggregation, wave balance, and sample summary
statistics. Sample and estimation mirror \texttt{3\_effect\_sae\_am.Rmd}
exactly (Callaway-Sant'Anna, school x cohort classes, not-yet-treated
controls, anticipation 2, universal base period,
\texttt{xformla\ =\ \textasciitilde{}num\_students}, region-clustered
multiplier bootstrap with 10,000 iterations, \texttt{set.seed(20260610)}
before every \texttt{att\_gt}). Heavy blocks cache to
\texttt{cache\_inference/}; set environment variable \texttt{SMOKE=1}
for a fast end-to-end test run.

\hypertarget{randomization-inference-over-the-1001-admissible-rollouts}{%
\subsection{Randomization inference over the 1,001 admissible
rollouts}\label{randomization-inference-over-the-1001-admissible-rollouts}}

Magallanes (pilot) and Metropolitana (last) are held at their actual
dates; the fourteen remaining regions are reassigned to the 2017/2018
waves in every one of the \(\binom{14}{4} = 1{,}001\) admissible ways
(exact enumeration; the observed assignment is one of them). For each
reassignment each school's treatment year is rebuilt from its region's
permuted wave, and the full estimator is re-run without bootstrap
(analytic standard errors). Exact two-sided \(p\)-values compare the
observed statistic with the permutation distribution; the studentized
statistic \(\hat{ATT}/\widehat{se}\) is primary, the raw \(\hat{ATT}\) a
check. The same runs give the joint pre-trend statistics over the clean
leads (event times \(-8\) to \(-4\)): the maximum absolute studentized
lead, and the sum of squared studentized leads, each also computed
excluding event time \(-8\).

Permutations run: 1001 of 1001 \textbar{} with any failed outcome: 0

\hypertarget{wild-cluster-bootstrap-at-the-region-level}{%
\subsection{Wild cluster bootstrap at the region
level}\label{wild-cluster-bootstrap-at-the-region-level}}

The Callaway-Sant'Anna multiplier bootstrap already draws region-level
Rademacher weights; the wild cluster bootstrap requires a regression
score, so it is applied to the TWFE analogue of the design: class-level
outcomes on a treatment indicator with school and admission-year fixed
effects and the class size control, on the panel with each treated
school's transition band (event times \(-1\), \(-2\)) set aside,
standard errors clustered on the sixteen regions. Restricted
(null-imposed) wild cluster bootstrap with Rademacher and Webb weights,
9,999 draws. Because one cluster (Metropolitana) holds a third of the
sample, the region-drawn bootstrap distribution can degenerate; the
subcluster variant of MacKinnon and Webb draws the weights at the school
level while keeping the variance clustered on regions, and is reported
alongside. The bootstrap \(|t^*|\) quantiles stored with the results
record the spread of each distribution.
